# WordShift update feed

This repository stores public WordShift release artifacts and signed manifests. Clients treat
GitHub as untrusted blob storage: authenticity comes from an Ed25519 public key pinned in the
client, not from this repository.

No demo release has been published yet. The updater source and threat model live in
[cross-platform-self-updater](https://github.com/joryeugene/cross-platform-self-updater).
